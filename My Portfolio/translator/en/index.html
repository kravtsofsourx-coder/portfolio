TranslatorGo

A mobile app for translating text, voice, and images into over 110 languages. The app is designed for travellers and people who regularly deal with language barriers.

My role

ASO Keywords analysis, Benchmark, Amplitude data analysis, Opportunity prioritisation, Prototypes, UI design

Team

4 people, including PO and PM

Main goal

Increase the conversion rate and build trust in the product from the very first seconds of use.

Solution

After analysing Amplitude data, I found that most users purchase a subscription right after completing the text-to-text translation flow. The solution was to optimise that journey — making it faster and more intuitive — and as a result, bring users closer to subscribing.

Research

After analysing competitors, App Store reviews, and quantitative data, I identified and prioritised solutions that helped improve key metrics.

Start screen

Problem

Users report that the app is hard to use — it takes too many taps to reach a specific feature, and it suffers from bugs.

Solution

Reduced cognitive load by focusing users' attention on the core features and hiding secondary ones. For example, removed the language combinations block that was taking up valuable screen space. Languages are now saved automatically.

Insight

App Store reviews and analytics reveal strong demand for voice translation and camera translation.

Solution

Placed strong emphasis on these two key features — they also help convert users into subscribers.

Insight

At the same time, data shows that users rarely save translations to the Phrasebook or add them to favourites.

Solution

Moved this functionality to the burger menu to avoid cluttering the main screen.

Problem

Some users complained about the app being difficult to use while on the move.

Solution

Moved the language selector to the bottom of the screen to make it easier to use with one hand.

Translation process

Problem

Going back or starting a new translation required tapping the "hide keyboard" icon at the bottom of the screen. This is a non-obvious action — users might think it simply hides the keyboard rather than returning to the previous screen.

Solution

Introduced a more standard and clear way to close the current translation or start a new one — via a link in the top navigation bar.

Problem

The Paste button is shown even when the clipboard is empty.

Solution

Show the Paste button only when the user has copied text in the clipboard.

A voice input option was also added — so if the user decides to use that feature, they won't need to go back to the start screen.

The full translation flow. On the result screen, a button was added at the bottom to quickly start a new translation.

Offline mode

When the internet connection is lost, offline mode activates automatically. It can also be enabled manually — for example, to save mobile data while abroad. When active, the interface changes the colour of certain elements to visually indicate that some features will be limited. For instance, the list of available languages will be restricted and simultaneous translation will be unavailable.

Visual update

Problem

The utilities market is crowded with similar-looking apps that are hard to tell apart. Users expect a modern, premium experience from a product they pay for.

Solution

The design focuses on key features — without unnecessary visual noise. Every time the app is opened, the user sees a unique image of a place associated with the selected language, making the product feel alive rather than templated.

Results

  • Conversion rate from free users to subscribers grew by 10%.
  • Translation frequency per user per session increased.
  • Positive return rate dynamics observed 30 days after the redesign.
